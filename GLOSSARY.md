# GLOSSARY.md — Abyss v2 Ubiquitous Language

Four Bounded Contexts (`sessions`, `agent`, `artifacts`, `skills`) plus `shared`.

| Term | Bounded Context | Definition |
| :--- | :--- | :--- |
| **Project** | `sessions` | Durable workspace aggregate binding a canonical local repository path (`workspace_path`) to its child `Session` threads and shared `ProjectMemory` (`ON DELETE CASCADE`). |
| **ProjectMemory** | `sessions` / `agent` | Persistent per-project knowledge file stored at `.abyss-data/memories/projects/{project_id}/AGENTS.md` (mounted read/write at `/memories/project/AGENTS.md` in coding modes, read-only in `ask` mode), isolated across projects and managed by `ProjectMemoryStore` (`domains/sessions/memory_store.py`) and `DynamicMemoryMiddleware`. |
| **Session** | `sessions` | Durable conversation thread bound to a parent `Project` (`workspace_path`), `RunMode`, message history, and SQLite checkpoint ID (`thread_id`). |
| **Workspace** | `agent` | Local filesystem directory selected by the user in the UI sidebar as the repository root for agentic search, diff inspection, and code edits (`WorkspaceInspector`, `git_utils.py`). |
| **RunMode** | `sessions` / `agent` | Execution policy toggled in the chat composer: **`ask`** (read-only exploration, shell disabled, instant `walkthrough`), **`plan`** (writes `implementation_plan`, pauses at `plan_review` interrupt, gates shell calls), or **`auto`** (executes immediately while still gating destructive shell commands and recording artifacts). |
| **RunCatalog** | `agent` | Immutable per-run configuration snapshot (`session_id`, `project_id`, `workspace_path`, `mode`, `artifacts_dir`, `project_memory_dir`, `ShellGuard`, `GitEvidenceTracker`, extra skills dirs) resolved dynamically via `RunContext` so one cached DeepAgents graph serves multiple runs safely. |
| **RunContext** | `agent` | Async `contextvars.ContextVar` binding the active `RunCatalog` for the duration of a single `stream_run` or `stream_resume` execution. |
| **DynamicRunBackend** | `agent` | Per-run DeepAgents composite backend (`domains/agent/run_backends.py`, along with `DynamicGuardedShellBackend`) routing `/artifacts/`, `/memories/project/`, `/skills/`, and the workspace root dynamically from `RunContext`. |
| **ArtifactWorkflowMiddleware** | `agent` | Agent middleware (`domains/agent/middleware/workflow.py`) coordinating task checklist sync, workspace/memory write guards, `ShellGuard` checks, and LangGraph `plan_review` / `shell_approval` HITL interrupts. |
| **LLMCredentials** | `shared` | Ephemeral per-request OpenAI-compatible credentials (`base_url`, `model`, `api_key`, `enable_thinking`) supplied solely from browser UI Settings via `X-LLM-*` headers (parsed in `shared/http.py`); masked in `__repr__`/`__str__`, scrubbed by `shared/logging.py`, and never persisted on the server. |
| **ShellGuard** | `agent` | Pure-stdlib 2-tier command evaluator (`ALLOW`, `REQUIRE_APPROVAL`, `BLOCK`) enforcing the hard deny-list, destructive command detection per `RunMode`, and secret output scrubbing. |
| **SkillStore** | `skills` | Domain store (`domains/skills/store.py` + `registry_client.py` + `frontmatter.py`) managing built-in (`backend/app/domains/skills/builtin/`), global (`.abyss-data/skills/`), and workspace (`.agents/skills/`) Agent Skills plus `skills.sh` catalog discovery, preview, and atomic tarball installation. |
| **SkillFiles** | `agent` | Read-only virtual `BackendProtocol` (`domains/agent/skill_backend.py`) aggregating built-in (`backend/app/domains/skills/builtin/`), global (`.abyss-data/skills/`), and target `Workspace` `.agents/skills/` / `.claude/skills/` per active run without cross-session leakage. |
| **GitEvidence** | `agent` | Pre-turn and post-mutation Git snapshot tracker (`branch`, `head`, `dirty` files, powered by `domains/agent/git_utils.py`) used to emit `diff_changed` events and link runs to verified workspace changes. |
| **Artifact** | `artifacts` | Pure document/diff-plan storage domain (`ArtifactStore`, zero LangGraph/LangChain imports) persisting Antigravity markdown documents in `.abyss-data/artifacts/{session_id}/` (mounted at `/artifacts/`): `implementation_plan`, `task`, and `walkthrough`. |
| **WalkthroughChunk** | `artifacts` | Logical change unit (`title`, `explanation`, `file_hunks`) indexing git diff hunks (`+12`, `-40`) across files so code-change walkthroughs jump directly into the Diff Viewer. |
| **Interrupt** | `agent` / `sessions` | LangGraph HITL pause point (`plan_review` before workspace mutation in `plan` mode, or `shell_approval` before guarded shell execution) surfaced as `PendingInterrupt` and resumed via `POST /api/sessions/{id}/resume`. |
